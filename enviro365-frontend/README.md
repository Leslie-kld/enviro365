# Enviro365 Frontend

React + Vite dashboard for the withdrawal system. See the root [README.md](../README.md) for full setup and feature documentation.

Quick start:

```bash
npm install
npm run dev
```

The app runs at `http://localhost:5173` and expects the backend at `http://localhost:8080` (override with a `VITE_API_BASE_URL` env variable).
